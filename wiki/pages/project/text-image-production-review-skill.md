# Text-image and production review skill

[`review-book-text-image-production`](../../../.agents/skills/review-book-text-image-production/SKILL.md)
reviews an ordered illustrated book as the reader encounters it. It bridges the
gap between manuscript-only evaluation, specialist continuity reviews, and PDF
preflight.

The review audits adjacent-page reader state, text-image agreement, character
entrances, location/time transitions, action screen direction, object
transformation and scale, accessible text contrast, and leaked proof markers.
It assigns each finding to the artifact layer that can repair it and names the
specialist evaluators that must rerun.

The skill does not rewrite stories, regenerate images, or replace the emotional
and environment/prop reviewers.
